# 🎧 Звонилка

Лёгкий сервер общения в реальном времени: **чат + голосовые звонки (WebRTC) + профили**.
Без внешних зависимостей — чистый Node.js + HTML/CSS/JS. Минимум нагрузки на ПК, низкий пинг.

## ✨ Что умеет
- 🗨 **Общий чат** с никами, аватарами и цветами
- 🔴 **Присутствие** — видно кто в сети (справа)
- 📞 **Голосовые звонки** по WebRTC (peer-to-peer, прямой аудиоканал — минимальная задержка)
- ⚙ **Настройки профиля** — ник, аватар, цвет, статус
- 🔗 **Комнаты по коду** — один код у тебя и у кента = одна комната
- 📡 **Индикатор пинга** в шапке

## 🚀 Запуск

Нужен [Node.js](https://nodejs.org) 16+.

```bash
node server.js
# или
npm start
```

Открой <http://localhost:3000>, впиши ник — и всё.

## 👥 Как позвать кента

1. Запусти сервер (на любой машине или VPS).
2. В настройках нажми **«Копировать»** — получишь ссылку-приглашение вида
   `http://IP:3000/?room=код`.
3. Скинь ссылку кенту. Он впишет ник и попадёт в ту же комнату.
4. Справа в списке «В сети» жми 📞 — пойдёт звонок.

💡 В одной сети ПК доступны по локальному IP. Для звонков из разных городов — задеплой
на любой бесплатный хостинг (Render, Railway, Fly.io) или VPS.

## ⚙ Голос (WebRTC) — важное

- Звонки идут **напрямую между браузерами** (P2P), поэтому пинг минимальный.
- Для «пробивания» NAT используется публичный STUN-сервер Google (настроен по умолчанию).
- В сложных сетях (симметричный NAT) может понадобиться TURN-сервер — впиши свои
  `iceServers` в `public/app.js` (переменная `ICE_SERVERS`).
- Микрофон запрашивается один раз при входе в звонок. HTTPS нужен, чтобы браузер отдал
  микрофон не на localhost (на localhost работает и по http).

## 📁 Структура
```
zvonilka/
├── server.js        # сервер: HTTP-статика + свой WebSocket (без зависимостей)
├── package.json
└── public/
    ├── index.html   # каркас
    ├── style.css     # стили
    └── app.js        # клиентская логика + WebRTC
```

## 🛠 Настройка
- **Порт**: переменная окружения `PORT` (по умолчанию 3000).
- **Профили** хранятся в памяти сервера; при перезапуске сбрасываются (можно расширить до файла/БД).

## ☁ Бесплатный деплой на Render.com (рекомендуется)

GitHub Pages не подойдёт — там нельзя запускать Node-сервер. Зато Render даёт бесплатный
запуск + HTTPS (нужен, чтобы браузер отдал микрофон).

### Шаг 1 — залей на GitHub
1. Создай на github.com новый **пустой** репозиторий (например `zvonilka`).
2. У себя в папке проекта выполни:
   ```bash
   cd zvonilka
   git init
   git add .
   git commit -m "zvonilka"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ-ЛОГИН/zvonilka.git
   git push -u origin main
   ```

### Шаг 2 — подключи Render
1. Зайди на <https://render.com> и войди **через GitHub**.
2. Нажми **New + → Web Service**.
3. Выбери свой репозиторий `zvonilka`.
4. Render сам поймёт (увидит Dockerfile). Оставь настройки по умолчанию,
   план — **Free**.
5. Жми **Create Web Service**.

Через пару минут получишь ссылку вида `https://zvonilka.onrender.com`.

> **⚡ Один нюанс на бесплатном тарифе:** сервис засыпает после ~15 минут простоя
> и «просыпается» до минуты при первом заходе. Для постоянного онлайна — плати
> копейки за «always-on» либо публикуй аптайм-пинг (например через UptimeRobot).

### Шаг 3 — общайтесь
Кидай кенту ссылку `https://zvonilka.onrender.com`, вписывайте ники, жмите 📞.

> Также в репо лежит `render.yaml` (Blueprint) — деплой в один клик: в Render жми
> **New + → Blueprint** и укажи репозиторий. Тогда не нужен ручной Web Service.
